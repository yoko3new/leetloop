# LeetLoop

> 🌐 **语言：** [**🇺🇸 Read in English →**](./README.md) · 🇨🇳 简体中文（当前）

LeetLoop 是一款本地优先的 Chrome 插件，会在你做 LeetCode 题时记录提交，并按间隔重复安排复习。它帮助你了解“现在还会做哪些题”，而不只是统计做过多少题。

## 1. 安装与使用

### 安装

需要 Chrome 116 或更高版本。从源码构建还需要 Node.js 22.12 或更高版本：

```bash
npm ci
npm run build
```

如果下载的发布包已包含 `.output/chrome-mv3`，可以跳过构建步骤。

1. 在 Chrome 打开 `chrome://extensions`，启用右上角的**开发者模式**。
2. 点击**加载已解压的扩展程序**，选择项目或解压包中的 `.output/chrome-mv3`。
3. 打开 `leetcode.com/problems/*` 下的题目，点击工具栏中的 LeetLoop 图标，打开侧栏。

### 使用

照常做题并提交即可，LeetLoop 会自动记录结果并更新复习安排。侧栏的**今日**查看到期题，**题单**查看常见题单进度，**记录**查看每道题的详细历史。顶部可切换 **EN / 中文**，右上角齿轮可设置提醒。

更新已安装的插件时，在原扩展目录重新构建或覆盖文件，然后到 `chrome://extensions` 点击 LeetLoop 卡片上的**刷新**。保留原插件安装，才能继续使用已有的本地记录。

## 2. 功能介绍

- **自动记录：**记录通过和失败的提交、日期、耗时、尝试次数、语言，以及检测到的 LeetCode 页面提示或题解使用情况；不保存代码。
- **每日复习：**通过侧栏、扩展角标和可选的每日通知显示到期题。
- **题单进度：**支持 Blind 75、NeetCode 250 和 LeetCode 热题 100，显示整体及主题进度；展开主题可看每题的首刷日期、复习次数和最近复习日期。
- **按题汇总：**同一题的重复提交和多种解法合并为一条可展开记录，同时保留每次提交的明细。
- **类似题建议：**复习表现提示需要巩固时，推荐相关题目继续练习。
- **中英切换：**默认英文，侧栏顶部切换英文或简体中文后，选择会保存在本地。

## 3. 记忆系统

LeetLoop 使用 FSRS，并结合刷题过程中的信号安排复习：提交结果、首刷或复习、同一会话的尝试次数、耗时、题目难度，以及检测到的提示或题解使用情况。

- 首次通过会启动该题的学习计划，并不直接代表已经掌握。
- 复习失败会作为遗忘信号，把下次复习提前；同一学习会话连续失败只评分一次。
- 同一会话中的重复通过会留在提交历史里，但不会反复增加复习评分。
- 提前复习成功后，从当天按当前复习间隔重新计算下次日期；如果过程比较吃力，下次复习也可能提前。

这些评分只用于安排复习，不能证明独立完成或真实面试表现。

## 4. 代码架构

| 模块 | 职责 |
| --- | --- |
| `leetcode.content` | 观察你主动打开的题目页，并发送提交事件。 |
| `background` | 去重、保存记录、更新复习排期、角标和通知。 |
| `sidepanel` | 展示今日复习、题单、记录、设置及语言切换。 |

项目使用 TypeScript、React、WXT（Manifest V3）、Dexie + IndexedDB 和 `ts-fsrs`。检查与打包命令：

```bash
npm run compile
npm test
npm run build
npm run zip
```

可加载的插件目录是 `.output/chrome-mv3`，ZIP 包位于 `.output`。

## 5. 限制与隐私

- 目前只支持 `leetcode.com`；`leetcode.cn` 需要单独的站点适配。
- 插件从安装后开始记录，不会自动导入过去完成的题；再次提交时，该题会进入系统。
- 记录和设置只保存在当前浏览器，不支持跨设备同步；卸载插件会删除本地记录。
- LeetCode 页面改版后，提交识别可能需要更新。插件能检测站内打开的提示，但无法知道你是否在其他网站看过答案。
- 插件不调用 LeetCode 未公开接口、不在后台轮询、不批量读取历史提交，也不保存代码、Cookie 或 LeetCode Session。
